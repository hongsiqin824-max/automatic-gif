- 本地上限不得高于平台真实上限：本地放行后平台报 300007 会被当成网关截断自动重试。

- 反代参数以 `sudo nginx -T` 为准：`/gif-monitor/` 3600s、body 64m。
- `ps -eo args` 会泄露 `.env` 密钥；只取 pid/comm。
- 只推 Gitee：`git push https://gitee.com/tsdka/automatic-gif.git main`（`git push gitee main` 会因第二个 GitHub 推送地址报 fatal，忽略即可，或直接按 URL 推）。
