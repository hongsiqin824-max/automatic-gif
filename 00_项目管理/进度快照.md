## 踩过的坑
- 大窗闪烁根因：视频宽度 `min(100%, (--stage-h - --stage-reserve)*16/9)`，当 `100%` 更小时视频跟栏宽走 → 滚动条占 15px → 视频变矮 8px → 滚动条消失 → 循环。右栏 `.stage-clip-preview{max-width:100%}` 同机制。
- 编辑已发布文章会把后台发布日期刷成编辑时刻 → 用户决定不管；统计/通知按首次发布时间。
- 工作台模式在无直播源比赛打不开大窗 → 本地联调用 `GIF_MONITOR_SOURCE_OVERRIDE` 指向测试流，或 `?mode=panel&match_id=`。
- Shell 工具的 `nohup ... &` 会随命令结束被回收，常驻服务必须用 `run_in_background`；日志写项目 `tmp/`，`/tmp` 被沙箱挡。
- `ps -eo args` 会把 `.env` 密钥全量打印进上下文，查进程只取 pid/comm。
- GitHub 直连时通时不通；走 `git push gitee main`（第二推送地址是 GitHub）这次一次成功。

## 关键决策
- 补图是独立队列类型 `manual_edit`（key `<原key>~edit<n>`），不动原发布记录 → 日报天然排除。
- 每次整篇重发，同一篇只允许一个更新在跑；待补发必须操作员点「更新帖子」才发。
- 闪烁修复接受唯一代价：经典滚动条下两栏右侧恒留约 15px 空白；浮层滚动条下为 0，零变化。不采用「视频只按高度定大小」（改动大、窄窗口视频会变小）。
