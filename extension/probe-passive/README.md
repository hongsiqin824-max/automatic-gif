# 直播站兼容性采集插件（给操作员）

装上后**正常看球就行**，不用做任何操作。插件会对每个开始播放的视频自动做一次 5 秒检测并记在本地，
用来统计各个直播站能不能被后续的「截 GIF 插件」支持。

- 不上传任何数据、不下载文件、每个站只录 5 秒、不影响播放。
- 记录只存在你的浏览器里，每天结束时复制一次发到群里即可。

## 安装（Chrome / Edge）

1. 把 `probe-passive.zip` 解压到一个**不会删**的目录（比如 `D:\gif-probe\`）。
2. 浏览器地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`），右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选刚才解压出来的 `probe-passive` 文件夹。
4. 工具栏出现「直播站兼容性采集」图标即可（可以点右侧拼图图标把它固定出来）。

浏览器每次启动可能弹一次「停用开发者模式扩展」提示，点「取消」或关掉即可，**不要点停用**。

## 每天做一次

1. 点工具栏的插件图标。
2. 点「复制 JSON」。
3. 粘贴到群里。

弹窗里的表格是给你自己看的：「画面」一列 **正常 / 黑屏 / 读不到** 就是我们要的结论；
「次」是这个站被看到的次数。

## 常见问题

- **弹窗里一直是空的**：确认视频真的在播（不是封面图），等 10 秒左右再点图标看。
- **某个站显示「读不到」或「黑屏」**：正常，这正是我们要收集的信息，继续正常用就好。
- **想重新开始统计**：点「清空」。
